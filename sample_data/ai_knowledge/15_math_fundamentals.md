# Toán Học Cơ Bản

## 1. Số học

### Các phép tính cơ bản
- Cộng (+): 5 + 3 = 8
- Trừ (-): 10 - 4 = 6
- Nhân (×): 6 × 7 = 42
- Chia (÷): 20 ÷ 4 = 5

### Phân số
- Phân số: a/b (a là tử, b là mẫu)
- Cộng phân số: a/b + c/d = (ad + bc) / bd
- Nhân phân số: a/b × c/d = ac/bd

### Số thập phân
- Chuyển phân số sang thập phân: 1/4 = 0.25
- Chuyển thập phân sang phân số: 0.75 = 3/4

## 2. Đại số

### Phương trình bậc nhất
- ax + b = 0 → x = -b/a
- Ví dụ: 2x + 6 = 0 → x = -3

### Phương trình bậc hai
- ax² + bx + c = 0
- Công thức nghiệm: x = (-b ± √(b²-4ac)) / 2a

### Bất phương trình
- a > b → a - c > b - c
- a > b, c > 0 → ac > bc
- a > b, c < 0 → ac < bc

## 3. Hình học

### Hình tam giác
- Diện tích: S = (a × h) / 2
- Chu vi: P = a + b + c
- Định lý Pytago: c² = a² + b² (tam giác vuông)

### Hình chữ nhật
- Diện tích: S = a × b
- Chu vi: P = 2(a + b)

### Hình tròn
- Diện tích: S = π × r²
- Chu vi: C = 2 × π × r

## 4. Thống kê

### Trung bình cộng
- (x₁ + x₂ + ... + xₙ) / n

### Trung vị
- Giá trị ở giữa khi sắp xếp tăng dần

### Mode
- Giá trị xuất hiện nhiều nhất

## 5. Xác suất

### Xác suất cơ bản
- P(A) = Số trường hợp thuận lợi / Tổng số trường hợp

### Định lý Bayes
- P(A|B) = P(B|A) × P(A) / P(B)
