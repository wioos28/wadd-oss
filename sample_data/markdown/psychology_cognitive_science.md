## 2. Cognitive Psychology

### Attention
- **Selective Attention**: Focus on specific stimuli
- **Divided Attention**: Multitasking
- **Sustained Attention**: Vigilance over time
- **Inattentional Blindness**: Missing obvious stimuli

### Memory Models
```
Sensory Memory → Short-term/Working Memory → Long-term Memory
    (iconic, echoic)     (7±2 items)           (unlimited)

Types of LTM:
- Explicit (Declarative)
  - Episodic (events)
  - Semantic (facts)
- Implicit (Non-declarative)
  - Procedural (skills)
  - Priming
```

### Memory Processes
- **Encoding**: Converting to memory
- **Storage**: Maintaining in memory
- **Retrieval**: Accessing from memory

### Forgetting
- **Decay**: Memory fades over time
- **Interference**: Other memories disrupt
  - Proactive: Old disrupts new
  - Retroactive: New disrupts old
- **Retrieval Failure**: Can't access (tip-of-tongue)

## 3. Perception

### Gestalt Principles
- **Proximity**: Nearby objects grouped
- **Similarity**: Similar objects grouped
- **Continuity**: Perceive continuous patterns
- **Closure**: Complete incomplete shapes
- **Figure-Ground**: Separate object from background

### Depth Cues
- **Binocular**: Binocular disparity
- **Monocular**: Linear perspective, relative size, texture gradient

## 4. Language & Cognition

### Chomsky's Theory
- **Universal Grammar**: Innate language capacity
- **Language Acquisition Device (LAD)**: Mental organ for language
- **Deep Structure vs Surface Structure**

### Linguistic Relativity (Sapir-Whorf)
- Language influences thought
- Strong version: Language determines thought
- Weak version: Language influences thought

## 5. Decision Making

### Heuristics
- **Availability**: Judge by ease of recall
- **Representativeness**: Judge by similarity to prototype
- **Anchoring**: Rely too heavily on first information

### Biases
- **Confirmation Bias**: Seek confirming evidence
- **Framing Effect**: Different choices based on presentation
- **Loss Aversion**: Losses hurt more than gains feel good
- **Dunning-Kruger**: Low ability overestimates, high ability underestimates

### Prospect Theory (Kahneman & Tversky)
- Value function: Concave for gains, convex for losses
- Probability weighting: Overweight small probabilities

## 6. Emotion

### Theories
- **James-Lange**: Emotion follows physiological response
- **Cannon-Bard**: Emotion and physiology simultaneous
- **Schachter-Singer**: Two-factor (arousal + cognition)
- **Appraisal Theory**: Emotion from evaluating events

### Basic Emotions (Ekman)
- Happiness, Sadness, Fear, Anger, Surprise, Disgust

## 7. Social Psychology

### Conformity (Asch)
- Majority influence
- Normative vs informational influence

### Obedience (Milgram)
- Authority figure influence
- 65% administered maximum shock

### Bystander Effect
- Diffusion of responsibility
- More bystanders = less helping

## 8. Developmental Psychology

### Piaget's Stages
| Stage | Age | Characteristics |
|-------|-----|-----------------|
| Sensorimotor | 0-2 | Object permanence |
| Preoperational | 2-7 | Egocentrism, animism |
| Concrete Operational | 7-11 | Conservation, logic |
| Formal Operational | 11+ | Abstract thinking |

### Kohlberg's Moral Development
1. Pre-conventional: Self-interest
2. Conventional: Social norms
3. Post-conventional: Universal principles

## 9. Personality
