# Chemistry Fundamentals

## 1. Atomic Structure

### Atomic Models
- **Thomson**: Plum pudding model
- **Rutherford**: Nuclear model
- **Bohr**: Energy levels
- **Quantum Mechanical**: Electron cloud

### Electron Configuration
```
1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d¹⁰ 4p⁶ ...

Aufbau principle: Fill lowest energy first
Hund's rule: Maximize unpaired electrons
Pauli exclusion: Max 2 electrons per orbital
```

## 2. Periodic Table

### Trends
| Property | Across Period | Down Group |
|----------|---------------|------------|
| Atomic radius | Decreases | Increases |
| Ionization energy | Increases | Decreases |
| Electronegativity | Increases | Decreases |
| Metallic character | Decreases | Increases |

### Element Groups
| Group | Elements | Properties |
|-------|----------|------------|
| Alkali metals | Li, Na, K... | Reactive, soft |
| Alkaline earth | Be, Mg, Ca... | Reactive |
| Halogens | F, Cl, Br... | Reactive nonmetals |
| Noble gases | He, Ne, Ar... | Unreactive |

## 3. Chemical Bonding

### Ionic Bonding
- Transfer of electrons
- Metal + Nonmetal
- High melting points
- Conduct electricity when dissolved

### Covalent Bonding
- Sharing of electrons
- Nonmetal + Nonmetal
- Polar vs nonpolar
- Single, double, triple bonds

### Metallic Bonding
- Delocalized electrons
- Metal atoms
- Good conductors
- Malleable, ductile

### Types

```
Fe + O₂ → Fe₂O₃

```

## 5. Stoichiometry

### Mole Concept
```
1 mole = 6.022 × 10²³ particles (Avogadro's number)
Molar mass = mass of 1 mole (g/mol)
```

### Calculations
```
Moles = mass / molar mass
Mass = moles × molar mass
Molarity = moles / volume (L)
```

## 6. Solutions

### Concentration Units
| Unit | Formula |
|------|---------|
| Molarity (M) | moles solute / L solution |
| Molality (m) | moles solute / kg solvent |
| Mass % | (mass solute / mass solution) × 100 |
| Mole fraction | moles solute / total moles |

### Colligative Properties
- Boiling point elevation: ΔTb = Kb × m
- Freezing point depression: ΔTf = Kf × m
- Osmotic pressure: π = MRT

## 7. Acids & Bases

### Definitions
- **Arrhenius**: H⁺ producer (acid), OH⁻ producer (base)
- **Brønsted-Lowry**: H⁺ donor (acid), H⁺ acceptor (base)
- **Lewis**: Electron pair acceptor (acid), donor (base)

### pH Scale
```
pH = -log[H⁺]

pH < 7: Acidic
pH = 7: Neutral
pH > 7: Basic
```

### Buffer Solutions
- Resist pH changes
- Weak acid + conjugate base
- Henderson-Hasselbalch: pH = pKa + log([A⁻]/[HA])

## 8. Thermochemistry

### Enthalpy
```
ΔH = Hproducts - Hreactants

Exothermic: ΔH < 0 (releases heat)
Endothermic: ΔH > 0 (absorbs heat)
```

### Hess's Law
ΔH is independent of path
Sum of ΔH for steps = ΔH for overall process

### Gibbs Free Energy
```
ΔG = ΔH - TΔS

ΔG < 0: Spontaneous
ΔG = 0: Equilibrium
ΔG > 0: Non-spontaneous
```

## 9. Chemical Kinetics

### Rate Laws
```
Rate = k[A]^m[B]^n

k: Rate constant
m, n: Reaction orders
```

### Factors Affecting Rate
- Temperature (Arrhenius equation)
- Concentration
- Surface area
- Catalysts
