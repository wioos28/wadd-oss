# Economics & Finance

## 1. Microeconomics

### Supply & Demand
```
Demand: Qd = a - bP (downward sloping)
Supply: Qs = c + dP (upward sloping)

Equilibrium: Qd = Qs
```

### Elasticity
```
Price Elasticity: Ed = (%ΔQd) / (%ΔP)

|Ed| > 1: Elastic
|Ed| < 1: Inelastic
|Ed| = 1: Unit elastic
```

### Market Structures
| Structure | Firms | Product | Entry |
|-----------|-------|---------|-------|
| Perfect Competition | Many | Identical | Easy |
| Monopolistic Competition | Many | Differentiated | Easy |
| Oligopoly | Few | Identical/Differentiated | Difficult |
| Monopoly | One | Unique | Blocked |

## 2. Macroeconomics

### GDP (Gross Domestic Product)
```
GDP = C + I + G + (X - M)

C: Consumption
I: Investment
G: Government spending
X: Exports
M: Imports
```

### Inflation
```
CPI = (Cost of basket in current year / Cost in base year) × 100

Inflation rate = (CPI₂ - CPI₁) / CPI₁ × 100%
```

### Money Supply
```
M0: Physical currency
M1: M0 + checking deposits
M2: M1 + savings + money market
M3: M2 + large deposits (discontinued in US)
```

## 3. Financial Markets

### Stock Market
- **Primary Market**: IPOs, new shares
- **Secondary Market**: Trading existing shares

### Bond Market
```
Bond Price = Σ(C/(1+r)ᵗ) + F/(1+r)ⁿ

C: Coupon payment
r: Yield to maturity
F: Face value
n: Years to maturity
```

### Derivatives
- **Options**: Right to buy/sell at strike price
- **Futures**: Obligation to buy/sell at future date
- **Swaps**: Exchange cash flows

## 4. Corporate Finance

### Capital Budgeting
```
NPV = Σ(CFₜ/(1+r)ᵗ) - Initial Investment

NPV > 0: Accept
IRR > Required Return: Accept
```

### Cost of Capital
```
WACC = (E/V × Re) + (D/V × Rd × (1-T))

E: Market value of equity
D: Market value of debt
Re: Cost of equity
Rd: Cost of debt
T: Tax rate
```

### Capital Structure
- **Modigliani-Miller**: Irrelevance theorem (with perfect markets)
- **Trade-off Theory**: Balance tax benefits vs bankruptcy costs
- **Pecking Order Theory**: Internal financing first

## 5. Investment Analysis

### Portfolio Theory
```
Portfolio Return: rp = Σ(wi × ri)
Portfolio Risk: σp = √(ΣΣ(wi × wj × σij))

Diversification reduces risk
```

### CAPM (Capital Asset Pricing Model)
```
E(Ri) = Rf + βi × (E(Rm) - Rf)

Rf: Risk-free rate
β: Systematic risk
Rm: Market return
```

### Efficient Market Hypothesis
- **Weak**: Past prices don't predict future
- **Semi-strong**: Public info reflected in prices
- **Strong**: All info reflected (including insider)

## 6. Behavioral Finance

### Biases
- **Overconfidence**: Overestimate abilities
- **Loss Aversion**: Losses hurt more than gains feel good
- **Anchoring**: Over-rely on first information
- **Herd Mentality**: Follow the crowd

### Prospect Theory
- Value function: Concave for gains, convex for losses
- Probability weighting: overweight small probabilities

## 7. Banking & Credit

### Money Creation
```
Money Multiplier = 1 / Reserve Requirement

ΔMoney Supply = ΔReserves × Money Multiplier
```

### Credit Markets
- **Interbank lending**: LIBOR, SOFR
- **Credit ratings**: AAA to D
- **Credit default swaps**: Insurance against default

## 8. International Finance

### Exchange Rates
```
Spot rate: Current exchange rate
Forward rate: Future exchange rate
PPP: Purchasing Power Parity

E(S) = S₀ × (1 + iₕ)/(1 + iբ)
```

### Balance of Payments
- **Current Account**: Trade in goods/services
- **Capital Account**: Asset transfers
- **Financial Account**: Investment flows
