# Biotechnology & Bioinformatics

## 1. Molecular Biology Basics

### Central Dogma
```
DNA → RNA → Protein
(Transcription) (Translation)
```

### DNA Structure
- Double helix
- Nucleotides: A-T, G-C base pairs
- Sugar-phosphate backbone
- 5' → 3' direction

### RNA Types
| Type | Function |
|------|----------|
| mRNA | Carries genetic code |
| tRNA | Transfers amino acids |
| rRNA | Ribosome component |
| miRNA | Gene regulation |

## 2. Genomics

### Sequencing Technologies
| Generation | Method | Speed | Cost |
|------------|--------|-------|------|
| 1st | Sanger | Slow | High |
| 2nd | Illumina | Fast | Low |
| 3rd | PacBio, Oxford | Real-time | Medium |

### Genome Assembly
```
Reads → Overlap → Contigs → Scaffolds → Genome

De novo assembly: No reference
Reference-based: Align to reference
```

### Variant Calling
- **SNP**: Single nucleotide polymorphism
- **Indel**: Insertion/deletion
- **CNV**: Copy number variation
- **SV**: Structural variation

## 3. Bioinformatics Tools

### Sequence Analysis
- **BLAST**: Sequence similarity search
- **ClustalW**: Multiple sequence alignment
- **FASTA**: Sequence comparison

### Gene Prediction
- **Augustus**: Gene prediction
- **GlimmerHMM**: Hidden Markov models
- **Prodigal**: Prokaryotic gene prediction

### Structural Biology
- **AlphaFold**: Protein structure prediction
- **Rosetta**: Protein design
- **PyMOL**: Molecular visualization

## 4. CRISPR & Gene Editing

### CRISPR-Cas9 System
```
Guide RNA (gRNA) → Target DNA
Cas9 protein → Cut DNA
Cell repair → Edit gene
```

### Applications
- Gene knockout/knockin
- Gene therapy
- Agricultural engineering
- Disease modeling

### Base Editing
- No double-strand break
- Precise nucleotide changes
- Cytosine base editors (C→T)
- Adenine base editors (A→G)

## 5. Proteomics

### Mass Spectrometry
```
Sample → Ionization → Mass Analyzer → Detector → Spectrum

Types: MALDI, ESI, SELDI
```

### Protein Identification
- Database search
- Peptide mass fingerprinting
- Tandem MS (MS/MS)

## 6. Systems Biology

### Pathway Analysis
- Metabolic pathways
- Signaling pathways
- Gene regulatory networks

### Network Biology
- Protein-protein interaction networks
- Gene co-expression networks
- Network topology analysis

## 7. Synthetic Biology

### Genetic Circuits
```
Input → Logic Gate → Output

AND gate: Two inputs required
OR gate: Either input sufficient
NOT gate: Inversion
```

### Applications
- Biosensors
- Drug production
- Biofuels
- Bioremediation

## 8. Bioinformatics Algorithms

### Sequence Alignment
- **Smith-Waterman**: Local alignment
- **Needleman-Wunsch**: Global alignment
- **BLAST**: Heuristic search

### Hidden Markov Models (HMM)
- Gene prediction
- Protein domain identification
- Profile analysis

### Phylogenetics
- Distance-based methods
- Maximum likelihood
- Bayesian inference
