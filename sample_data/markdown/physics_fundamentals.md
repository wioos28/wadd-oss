# Physics Fundamentals

## 1. Classical Mechanics

### Newton's Laws
1. **First Law**: Objects stay at rest or uniform motion unless acted upon
2. **Second Law**: F = ma
3. **Third Law**: Every action has equal and opposite reaction

### Kinematics
```
v = v₀ + at
x = x₀ + v₀t + ½at²
v² = v₀² + 2a(x - x₀)
```

### Energy
```
Kinetic: KE = ½mv²
Potential: PE = mgh (gravitational)
           PE = ½kx² (elastic)
Work: W = F × d × cos(θ)
Power: P = W/t = F × v
```

### Momentum
```
p = mv
Impulse: J = F × Δt = Δp
Conservation: m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'
```

## 2. Thermodynamics

### Laws
1. **Zeroth**: Thermal equilibrium is transitive
2. **First**: ΔU = Q - W (energy conservation)
3. **First**: ΔS ≥ 0 (entropy never decreases)
4. **Third**: S → 0 as T → 0

### Key Concepts
```
Temperature: Average kinetic energy
Heat: Energy transfer due to temperature difference
Entropy: Disorder measure
```

### Ideal Gas Law
```
PV = nRT

P: Pressure (Pa)
V: Volume (m³)
n: Moles
R: Gas constant (8.314 J/mol·K)
T: Temperature (K)
```

## 3. Electromagnetism

### Coulomb's Law
```
F = k × q₁q₂/r²

k = 9 × 10⁹ N·m²/C²
```

### Electric Field
```
E = F/q = kQ/r²
E = -dV/dr
```

### Maxwell's Equations
1. ∇ · E = ρ/ε₀ (Gauss's law)
2. ∇ · B = 0 (No magnetic monopoles)
3. ∇ × E = -∂B/∂t (Faraday's law)
4. ∇ × B = μ₀J + μ₀ε₀∂E/∂t (Ampère-Maxwell law)

## 4. Waves & Optics

### Wave Properties
```
v = fλ

v: Velocity
f: Frequency
λ: Wavelength
```

### Doppler Effect
```
f' = f × (v ± v₀)/(v ∓ vₛ)

v₀: Observer velocity
vₛ: Source velocity
```

### Optics
- **Reflection**: θᵢ = θᵣ
- **Snell's Law**: n₁sinθ₁ = n₂sinθ₂
- **Critical Angle**: θc = sin⁻¹(n₂/n₁)

## 5. Relativity

### Special Relativity
```
Time dilation: t' = t/√(1 - v²/c²)
Length contraction: L' = L√(1 - v²/c²)
Mass-energy: E = mc²
```

### Lorentz Transformation
```
x' = γ(x - vt)
t' = γ(t - vx/c²)

γ = 1/√(1 - v²/c²)
```

### General Relativity
- Gravity is curvature of spacetime
- Einstein field equations
- Gravitational waves
- Black holes

## 6. Quantum Mechanics

### Wave-Particle Duality
```
λ = h/p

h: Planck's constant (6.626 × 10⁻³⁴ J·s)
p: Momentum
```

### Schrödinger Equation
```
iℏ ∂Ψ/∂t = ĤΨ

Ψ: Wave function
Ĥ: Hamiltonian operator
```

### Heisenberg Uncertainty Principle
```
ΔxΔp ≥ ℏ/2

Position and momentum cannot both be precisely known
```

### Quantum States
- Superposition
- Measurement collapses to eigenstate
- Entanglement

## 7. Nuclear Physics

### Radioactive Decay
```
N(t) = N₀e^(-λt)

Half-life: t₁/₂ = ln2/λ
```

### Nuclear Reactions
- **Fission**: Split heavy nucleus
- **Fusion**: Combine light nuclei
- **Binding Energy**: E = Δmc²

## 8. Astrophysics

### Kepler's Laws
1. Elliptical orbits
2. Equal areas in equal times
3. T² ∝ a³
